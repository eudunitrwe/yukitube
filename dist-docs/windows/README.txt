YukiTube pentru Windows 10 / 11
===============================

YouTube intr-o fereastra proprie de Firefox, fara reclame si fara
„Video intrerupt. Continui vizionarea?”.

YukiTube porneste Firefox pe un profil separat, doar pentru YouTube.
Autentificarea, istoricul si extensiile nu se amesteca cu Firefox-ul tau
obisnuit. Bara de taburi e ascunsa, ca sa arate ca o aplicatie.

Extensii incluse (versiunile semnate de pe addons.mozilla.org; dupa
instalare, Firefox le actualizeaza singur):

  - uBlock Origin 1.77.0 (GPL-3.0, Raymond Hill): blocheaza reclamele,
    inclusiv pe cele video de pe YouTube.
  - YouTube NonStop 0.9.2 (MIT, Nikos Ioannou): inchide singur dialogul
    „Continui vizionarea?”.

Instalarea e descrisa in INSTALARE.txt.


FOLOSIRE

Deschide „YukiTube” din meniul Start (sau de pe desktop, daca ai ales
scurtatura). Butonul uBlock Origin din dreapta barei de adrese deschide
panoul lui.


SCURTATURI

  Alt+Stanga / Alt+Dreapta    Inapoi / inainte
  Ctrl+L                      Bara de adrese: lipeste un link sau cauta
  Ctrl+R / F5                 Reincarca
  F11                         Ecran complet
  Ctrl+= / Ctrl+- / Ctrl+0    Zoom
  Space, K, J, L, F, M        Playerul YouTube: pauza, inapoi/inainte
                              10 s, ecran complet, sunet
  ?                           Toate scurtaturile YouTube


UNDE STAU DATELE

Profilul (autentificare, istoric, setari uBlock) e in
%LOCALAPPDATA%\yukitube\profile


DE STIUT

Pe bara de activitati (taskbar), fereastra YukiTube se grupeaza impreuna
cu Firefox, pentru ca este tot Firefox.
